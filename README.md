## 方案建议（尚待用户确认）

React Native + Expo + TypeScript 手机客户端；相机、相册、定位和导航使用原生能力；本地 SQLite 保存私人餐食。临时午饭邀请提供 H5 入口，连接共享后端，使同事无需安装 APP 也能参与。

后端保持单个应用和数据库，按需加入私有对象存储与异步任务。后端语言、身份方案、地图和 AI 服务商尚未选定。地图地点数据与手机定位分开；获得坐标不等于获得真实餐馆资料。

推荐先以一个办公区内手动维护的真实餐馆验证闭环，不依赖未知授权的抓取。开发示例数据必须显式启用并标注，与用户真实餐馆、正式服务分离。
