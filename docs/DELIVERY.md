# V0.2 交付与验收

基线：[PRD V0.2](PRD.md) 与用户本轮要求。V0.2 取代 V0.1；旧 S1–S4、F01–F29、A01–A16 仅保存在 [archive](archive/README.md)，不再作为本轮交付门槛。

## 实施范围

- 继续使用原仓库、Git 授权与可追溯文档。开始时只有文档，没有产品代码或待迁移数据库；本轮没有清库或触碰其他项目。
- 已实现 React Native + Expo + TypeScript 双端客户端、SQLite、私有照片与缩略图、三个主要页面。这是本轮实施选择，不追认为此前用户已确认。
- 暂停餐馆池、预算/距离/口味设置、推荐、AI、营养、投票、账号、云同步、提醒和埋点。商家、支付、配送、社区不在本轮范围。
- 剩余核心工作是完成真实照片保存及重启恢复、权限/离线与双端手机验收。
