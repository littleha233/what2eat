| 证据类型 | 能说明 | 不能替代 |

| 规则单元测试 | 本地自然日计算、校验、确定输入下的状态行为 | 原生权限/图片持久化 |
| 宿主机真实 SQLite 集成 | SQL、增删改、幂等、数据库文件关闭重开 | Expo SQLite 桥接、手机文件系统、APP 重启 |
| iOS/Android JS bundle | 两个平台的 JS/资源可被打包 | 原生编译、安装、相机和离线体验 |
| 浏览器预览 | 部分布局与交互（若提供） | 手机 APP 验收 |
| 模拟器 | 已实际执行的原生界面/选图等行为 | 真机拍照以及未测试的另一端 |
| 真机 | 声明设备上实际运行的 L01–L10 | 未测试平台/系统版本或未来发布版本 |

记录每项的实际结果、错误和复现步骤；测试照片、设备数据库及本地证据保存在被忽略的 `local-data/`，不提交私人图片。10–20 秒记录耗时只是体验观察目标，若测量请说明设备和操作次数，不虚报性能通过。
