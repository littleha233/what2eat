## 复现隔离 iOS 存储检查

先构建当前 iOS Release 模拟器 `.app`（见 README）。在 Xcode 创建名称包含 `Storage Check` 的专用模拟器，通过 `xcrun simctl list devices` 获取其 UUID；不要选择需要保留测试数据的设备。将下面两项替换为专用模拟器 UUID 和完整的 `.app` 路径：

```bash
STORAGE_SMOKE_DEVICE="<专用模拟器 UUID>" \
STORAGE_SMOKE_BASE_APP="<Release 模拟器 app.app 完整路径>" \
node scripts/native-storage-smoke.mjs
```

脚本使用 `scripts/fixtures/storage-photo.jpg`：来自本项目此前生成的橙色几何合成测试图，不是用户餐食照片。它复用 Release 原生库并打入独立检查入口；Bundle ID 为 `com.littleha233.what2eat.storagecheck`。每次运行只重置这个测试包的数据，不操作生产 `com.littleha233.what2eat` 容器。结果、源代码哈希、执行日志与 `.app` 副本写入已忽略的 `local-data/native-storage-smoke-*/`。它验证实际运行的存储代码，不包含生产系统相册选图、权限提示或相机交互。
